# Rapports de test

Un fichier par ticket : `<TICKET-ID>.md`, avec une section par étape du plan. Chaque section est générée par `pnpm report <TICKET-ID> --step <n>` et commitée avec l'étape.

Format et règles : [../process/testing.md](../process/testing.md#rapport-de-test).

Ne pas éditer ces fichiers à la main, sauf les lignes « Remarques ».
