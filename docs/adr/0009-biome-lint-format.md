# ADR-0009 : Biome pour le lint et le formatage

- Statut : Accepted
- Date : 2026-10-03
- Décideurs : humain

## Contexte

Il faut un lint et un formatage uniformes, rapides, simples à configurer pour un agent.

## Décision

Biome (MIT), un seul outil pour le lint et le formatage, avec les règles recommandées et `noExplicitAny` en erreur.
