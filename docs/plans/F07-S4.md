## Étapes

### Étape 1 : avancer et reculer d'un plan

- Critères d'acceptance couverts : F07-S4-AC1, F07-S4-AC2, F07-S4-AC3, F07-S4-AC4, F07-S4-AC5
- Code applicatif :
  - `packages/model/src/order.ts` : `sortByZIndex(elements)`, `reorderStep(elements, ids, direction)` (nouvel ordre et nouvelles clés `zIndex` calculées par `generateKeyBetween`, ordre relatif conservé, `forward`/`backward`) et `canReorder(elements, ids, direction)` (au moins un élément peut bouger, F07-S4-AC3).
  - `packages/model/src/ops.ts` : `bringForward(doc, ids)`, `sendBackward(doc, ids)`, `canBringForward(doc, ids)`, `canSendBackward(doc, ids)` ; l'écriture des `zIndex` se fait dans une seule transaction à origine locale (F07-S4-AC5).
  - `packages/model/src/index.ts` : exporte le module `order`.
  - `apps/web/src/canvas/board-elements.tsx` : rend les éléments triés par `zIndex` croissant pour que l'ordre soit visible.
  - `apps/web/src/components/board/context-bar.tsx` : la barre apparaît pour toute sélection non vide ; les pastilles de couleur ne sont affichées que si la sélection contient un post-it ou un texte (UI-BOARD-8) ; les boutons `order-forward` et `order-backward` sont présents et désactivés aux limites (F07-S4-AC3).
  - `apps/web/src/tools/shortcuts.ts` : `useOrderShortcuts(doc)` pour `]` (avancer) et `[` (reculer) quand une sélection existe et hors édition de texte.
  - `apps/web/src/canvas/board-canvas.tsx` : active `useOrderShortcuts`.
- Code technique : aucun : les dépendances (yjs, `fractional-indexing`, react-konva, zustand) existent déjà.
- Code de test :
  - Unitaire : `packages/model/src/order.test.ts` (reorder `forward`/`backward`, limites, sélection multiple et ordre relatif, convergence de deux documents Yjs pour AC5), `apps/web/src/tools/order-shortcuts.test.tsx` (`]`/`[`), `apps/web/src/components/board/context-bar.test.tsx` (boutons, désactivation aux limites, sélection non recolorable).
  - E2E : `e2e/order.spec.ts` (`[F07-S4-AC1]`, `[F07-S4-AC2]`, `[F07-S4-AC3]`, `[F07-S4-AC4]`).
- Documentation et Markdown : `docs/architecture.md` (module `order.ts`, opérations, flux « Ordre »), `docs/glossary.md` (terme avancer/reculer), `docs/journal.md` (décisions, test hérité modifié), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F07-S4.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F07-S4-AC1 à AC5) ; sur un board à trois éléments A, B, C empilés, `]`/« Avancer » donne B, A, C, `[`/« Reculer » recule d'un plan, les boutons sont désactivés tout devant et tout derrière, une sélection multiple conserve son ordre relatif, et deux documents Yjs modifiés concurremment convergent.
