## Étapes

### Étape 1 : déplacer au glisser, aux flèches, annulation unique et fluidité

- Critères d'acceptance couverts : F07-S2-AC1, F07-S2-AC2, F07-S2-AC3, F07-S2-AC4, F07-S2-AC5
- Code applicatif :
  - `packages/model/src/ops.ts` : `moveElements(doc, ids, delta)` déplace `x`/`y` (et les extrémités d'une flèche) de tous les éléments indiqués dans une seule transaction à origine locale.
  - `packages/model/src/history.ts` : `createBoardHistory(doc)` crée un `Y.UndoManager` limité à `LOCAL_ORIGIN` ; type `BoardHistory`.
  - `packages/model/src/index.ts` : exporte `moveElements`, `createBoardHistory` et `BoardHistory`.
  - `apps/web/src/collab/history-context.ts` : contexte React et hook `useBoardHistory()`.
  - `apps/web/src/collab/use-board-connection.ts` : crée l'historique avec le document et le détruit à la fermeture.
  - `apps/web/src/app/board-page.tsx` : fournit `HistoryContext`.
  - `apps/web/src/canvas/use-select.ts` : un glisser sur un élément (déjà) sélectionné déplace toute la sélection ; positions intermédiaires écrites au plus toutes les 50 ms ; `stopCapturing()` encadre le glisser pour une seule entrée d'annulation (F07-S2-AC3).
  - `apps/web/src/tools/shortcuts.ts` : `useMoveShortcuts(doc)` (flèches 1, Shift 10, F07-S2-AC2) et `useUndoShortcut(history)` (`Ctrl+Z`, requis par F07-S2-AC3).
  - `apps/web/src/canvas/board-canvas.tsx` : branche les raccourcis et transmet l'historique à `useSelect`.
- Code technique : aucun : les dépendances (yjs, zustand, react-konva) existent déjà.
- Code de test :
  - Unitaire : `packages/model/src/ops.test.ts` (`moveElements` : plusieurs éléments, flèche, id absent), `packages/model/src/history.test.ts` (`[F07-S2-AC3]` : plusieurs transactions de glisser annulées en une fois), `apps/web/src/tools/move-shortcuts.test.tsx` (`[F07-S2-AC2]` : flèches et Shift).
  - E2E : `e2e/move.spec.ts` (`[F07-S2-AC1]`, `[F07-S2-AC2]`, `[F07-S2-AC3]`).
  - Fluidité : `e2e/fluidity/board-move.spec.ts` (`[F07-S2-AC4]` : FL-1, FL-2, FL-3 sur 300 éléments), `e2e/fluidity/board-move-remote.spec.ts` (`[F07-S2-AC5]` : FL-4 et FL-5 à deux utilisateurs).
- Documentation et Markdown : `docs/architecture.md` (déplacement, historique, opération `moveElements`), `docs/glossary.md` (`BoardHistory`), `docs/journal.md` (décisions et tests), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F07-S2.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F07-S2-AC1 à AC5) ; un glisser déplace toute la sélection, les flèches la déplacent de 1/10 unité(s), un long glisser suivi de `Ctrl+Z` restaure la position de départ en une seule annulation, et les mesures de fluidité locale et distante sont sous les seuils de F00.
