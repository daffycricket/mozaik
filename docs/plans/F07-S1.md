## Étapes

### Étape 1 : sélectionner au clic, au clavier et au rectangle

- Critères d'acceptance couverts : F07-S1-AC1, F07-S1-AC2, F07-S1-AC3, F07-S1-AC4, UI-BOARD-10
- Code applicatif :
  - `packages/model/src/geometry.ts` : `boxFromPoints(a, b)` (rectangle normalisé à partir de deux coins, pour le rectangle de sélection).
  - `packages/model/src/ops.ts` : `elementsInBox(elements, box)` (éléments entièrement contenus, pour F07-S1-AC3).
  - `apps/web/src/state/selection-store.ts` : action `toggle(id)` (F07-S1-AC2).
  - `apps/web/src/canvas/selection-handles.ts` : `HANDLE_SIZE` et `selectionHandleCenters(box)` (8 centres : coins et milieux des côtés), partagés par le rendu Konva et `window.__board`.
  - `apps/web/src/canvas/selection-overlay.tsx` : cadre + 8 poignées carrées (UI-BOARD-10) et rectangle de sélection (`--selection-fill`, `--selection`).
  - `apps/web/src/canvas/use-select.ts` : interactions de sélection (clic, Shift+clic, rectangle depuis une zone vide, `Ctrl+A`, Échap, clic dans le vide), inactives pendant le pan (outil Main ou Espace).
  - `apps/web/src/canvas/board-canvas.tsx` : branche `use-select` et rend le rectangle de sélection.
  - `apps/web/src/testing/board-api.ts` : `getOverlayBoxes()` réutilise `selectionHandleCenters` pour les 8 poignées.
  - `apps/web/src/lib/theme-tokens.ts`, `apps/web/src/index.css`, `docs/design/charte.md` : jeton `--handle-fill` (fond des poignées), pour éviter une couleur en dur.
- Code technique : aucun : les dépendances (zustand, react-konva) existent déjà.
- Code de test :
  - Unitaire : `packages/model/src/geometry.test.ts` (`boxFromPoints`), `packages/model/src/ops.test.ts` (`elementsInBox`), `apps/web/src/state/selection-store.test.ts` (`toggle`, `setSelection`, `clearSelection`), `apps/web/src/canvas/selection-handles.test.ts` (8 centres, UI-BOARD-10).
  - E2E : `e2e/selection.spec.ts` (F07-S1-AC1, AC2, AC3, AC4), `e2e/layout/board-selection.spec.ts` (UI-BOARD-10, aux deux viewports de référence).
- Documentation et Markdown : `docs/architecture.md` (sélection : `use-select.ts`, poignées, rectangle, `elementsInBox`, jeton `--handle-fill`), `docs/journal.md` (décisions et tests), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F07-S1.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F07-S1-AC1 à AC4 et UI-BOARD-10) ; un clic sélectionne un seul élément avec son cadre et ses 8 poignées, Shift+clic ajoute/retire, un rectangle tracé depuis le vide sélectionne les éléments entièrement contenus, `Ctrl+A` sélectionne tout et Échap ou un clic dans le vide désélectionne.
