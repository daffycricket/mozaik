## Étapes

### Étape 1 : dialogue de nom avant l'entrée dans un board

- Critères d'acceptance couverts : F10-S1-AC1, F10-S1-AC2, F10-S1-AC3, F10-S1-AC4, F10-S1-AC5, F10-S1-AC6, UI-NAME-1, UI-NAME-2
- Code applicatif :
  - `apps/web/src/identity/identity.ts` : schéma zod de l'identité (`{ id, name }`), `validateName` (1 à 30 caractères après `trim`, caractères de contrôle refusés), `createIdentity`, `loadStoredIdentity` / `storeIdentity` sur `localStorage` (clé `mozaik.identity`).
  - `apps/web/src/identity/name-dialog.tsx` : dialogue shadcn/ui (`dialog`, `input`, `label`, `button`), champ `name-input`, erreur `name-error`, lien `name-back`, bouton `name-submit`, non fermable par Échap ni clic extérieur.
  - `apps/web/src/app/board-page.tsx` : la page board affiche le dialogue tant qu'aucune identité n'est mémorisée, puis monte la connexion collaborative (`BoardView`).
  - `apps/web/src/components/ui/dialog.tsx`, `input.tsx`, `label.tsx` : composants shadcn/ui ajoutés par la CLI (Base UI), normalisés sur `@/lib/utils`.
- Code technique :
  - `playwright.config.ts` : état de stockage par défaut avec une identité mémorisée, pour que les tests e2e hérités qui entrent dans un board restent inchangés ; les tests de F10-S1 repartent d'un stockage vide.
  - `e2e/support/identity.ts` : clé et identité de test partagées.
- Code de test :
  - Unitaire : `apps/web/src/identity/identity.test.ts` (`validateName`, chargement/écriture/mémoire corrompue) ; `apps/web/src/app/pages.test.tsx` (page board sans identité → pas de canvas ; avec identité → canvas).
  - E2E : `e2e/name-dialog.spec.ts` (F10-S1-AC1 à AC6) ; `e2e/layout/name-dialog.spec.ts` (UI-NAME-1, UI-NAME-2).
- Documentation et Markdown : `docs/journal.md` (décisions et test hérité modifié), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F10-S1.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F10-S1 et les règles `UI-NAME-*`), et une URL `/b/<id>` ouverte sans nom mémorisé n'ouvre pas de connexion collaborative avant validation.
