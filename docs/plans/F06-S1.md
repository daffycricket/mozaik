# Plan : F06-S1 Tracer une flèche

- Ticket : [backlog](../backlog.md), story [F06-S1](../features/F06-fleches.md#f06-s1--tracer-une-flèche)
- Critères d'acceptance visés : F06-S1-AC1, F06-S1-AC2, F06-S1-AC3, F06-S1-AC4
- Branche : `feat/F06-S1-draw-arrow`

## Synthèse des étapes

| N° | Nom | Description | Critères d'acceptance |
|---|---|---|---|
| 1 | Tracer une flèche | L'outil Flèche (`A`) trace au glisser un segment libre de A vers B (pointe à l'arrivée, style fixe `#1f2937`/2), l'aperçu suit le pointeur sans écrire dans Yjs, la flèche est créée en une transaction locale si le glisser fait au moins 10 unités, sélectionnée, puis l'outil revient à Sélection ; un glisser plus court ne crée rien ; la flèche reste indépendante des post-its. La sélection d'une flèche affiche deux poignées rondes sans cadre (UI-BOARD-10). | F06-S1-AC1 : tracé A→B, sélection, retour à Sélection ; F06-S1-AC2 : glisser < 10 unités sans création ; F06-S1-AC3 : indépendance ; F06-S1-AC4 : fluidité du tracé (FL-1, FL-2) |

## Étapes

### Étape 1 : tracer une flèche

- Critères d'acceptance couverts : F06-S1-AC1, F06-S1-AC2, F06-S1-AC3, F06-S1-AC4
- Code applicatif :
  - `packages/model/src/schema.ts` : `ARROW_MIN_LENGTH` (10), longueur minimale d'un glisser de flèche (F06-S1-AC2).
  - `packages/model/src/geometry.ts` : `ArrowPoints` et `arrowFromDrag(start, end)` (extrémités du segment, ou `null` si le glisser est trop court).
  - `packages/model/src/ops.ts` : `createArrow(doc, start, end, options)` en transaction locale.
  - `apps/web/src/state/tool-store.ts` : outil `arrow`.
  - `apps/web/src/tools/shortcuts.ts` : raccourci `A` (flèche).
  - `apps/web/src/components/board/toolbar.tsx` : bouton `tool-arrow` après `tool-text`.
  - `apps/web/src/state/draft-store.ts` : aperçu local d'une flèche en cours de tracé (`Draft` = forme ou flèche), état d'interface Zustand.
  - `apps/web/src/canvas/use-draw-arrow.ts` : geste pointeur de tracé (seuil de glisser, aperçu, création au relâchement si longueur ≥ 10).
  - `apps/web/src/canvas/board-elements.tsx` : nœud Konva `ArrowNode` (segment + pointe, `SHAPE_STROKE`, `SHAPE_STROKE_WIDTH`) et rendu des flèches persistées.
  - `apps/web/src/canvas/selection-overlay.tsx` : `ArrowSelectionOverlay` (deux poignées rondes, sans cadre, UI-BOARD-10).
  - `apps/web/src/canvas/board-canvas.tsx` : branche le tracé, affiche l'aperçu de flèche et choisit l'overlay adapté à la sélection.
  - `apps/web/src/testing/board-api.ts` : `getDraftShape()` renvoie aussi une flèche ; `getOverlayBoxes()` expose les deux poignées d'une flèche seule sélectionnée.
  - `apps/web/src/app/board-page.tsx` : alimente `getDraftShape` depuis le store d'aperçu.
- Code technique : aucun : les dépendances (zustand, react-konva, lucide-react) existent déjà.
- Code de test :
  - Unitaire : `packages/model/src/arrow.test.ts` (`arrowFromDrag` AC1/AC2, `createArrow` AC1, indépendance AC3), `apps/web/src/tools/arrow-shortcuts.test.tsx` (`A`), `apps/web/src/components/board/arrow-tools.test.tsx` (`tool-arrow`), `apps/web/src/state/draft-store.test.ts` (aperçu de flèche, AC4), `apps/web/src/testing/arrow-overlay.test.ts` (deux poignées rondes d'une flèche, UI-BOARD-10).
  - E2E : `e2e/arrow-create.spec.ts` (F06-S1-AC1 à AC3), `e2e/fluidity/arrow-create.spec.ts` (F06-S1-AC4, FL-1 et FL-2 sur un board de 300 éléments), `e2e/layout/board-arrow-selection.spec.ts` (UI-BOARD-10).
- Documentation et Markdown : `docs/architecture.md` (outil Flèche, aperçu de tracé, overlay de flèche), `docs/journal.md` (décisions), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F06-S1.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F06-S1-AC1 à AC4) ; un glisser avec `A` crée une flèche de A vers B, sélectionnée, l'outil revient à Sélection ; un glisser de moins de 10 unités ne crée rien ; déplacer un post-it ne déplace pas la flèche ; et le tracé d'une flèche sur un board de 300 éléments respecte FL-1 (≤ 150 ms) et FL-2 (médiane ≤ 33 ms, aucun intervalle > 200 ms).
