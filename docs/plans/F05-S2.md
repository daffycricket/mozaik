## Étapes

### Étape 1 : couleur du texte

- Critères d'acceptance couverts : F05-S2-AC1, F05-S2-AC2, F05-S2-AC3
- Code applicatif : aucun : le comportement est déjà livré par F03-S3. `setElementsColor` (`packages/model/src/ops.ts`) traite `sticky` et `text` dans une seule transaction à origine locale ; `ContextBar` (`apps/web/src/components/board/context-bar.tsx`) affiche les dix pastilles dès que la sélection contient un post-it ou un texte, marque la couleur courante `aria-pressed="true"` et n'en marque aucune si les couleurs diffèrent ; le rendu applique la teinte « fond » aux post-its et la teinte « texte » aux textes (`apps/web/src/canvas/board-elements.tsx`). F05-S2 formalise ce comportement pour les textes et le couvre par des tests nommés.
- Code technique : aucun : les dépendances (zustand, react-konva, toggle-group) existent déjà.
- Code de test :
  - Unitaire : ajouts à `apps/web/src/components/board/context-bar.test.tsx` (F05-S2-AC1 : deux textes sélectionnés recolorés par `color-red` ; F05-S2-AC2 : dix couleurs présentes et couleur courante `black` marquée ; F05-S2-AC3 : sélection mixte post-it + texte recolorée).
  - E2E : `e2e/text-color.spec.ts` (F05-S2-AC1, F05-S2-AC2, F05-S2-AC3) : création d'un texte par l'outil Texte, palette, recoloration et sélection mixte avec un post-it semé.
- Documentation et Markdown : `docs/architecture.md` (le changement de couleur vaut aussi pour les textes, F05-S2), `docs/journal.md` (décision), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F05-S2.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F05-S2-AC1 à AC3), sélectionner un ou plusieurs textes affiche la barre contextuelle avec les 10 couleurs et la couleur courante marquée, choisir `red` met `color = red` sur tous les textes sélectionnés, et une sélection mixte de post-its et de textes prend la couleur choisie.
