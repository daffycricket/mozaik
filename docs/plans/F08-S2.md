## Étapes

### Étape 1 : annuler, rétablir, isolation et boutons

- Critères d'acceptance couverts : F08-S2-AC1, F08-S2-AC2, F08-S2-AC3
- Code applicatif :
  - `apps/web/src/tools/shortcuts.ts` : `useHistoryShortcuts(history)` remplace `useUndoShortcut` : `Ctrl+Z` annule, `Ctrl+Shift+Z` rétablit, inactif pendant la saisie d'un texte.
  - `apps/web/src/collab/use-history-state.ts` (nouveau) : hook abonné aux événements du `Y.UndoManager`, expose `{ canUndo, canRedo }` pour l'interface.
  - `apps/web/src/components/ui/separator.tsx` (nouveau) : composant shadcn/ui `separator` sur la primitive Base UI, requis par `UI-BOARD-3`.
  - `apps/web/src/components/board/toolbar.tsx` : ajoute un séparateur puis les boutons `undo` et `redo` (variante `ghost`, `aria-label` « Annuler » / « Rétablir »), désactivés par `canUndo`/`canRedo` et branchés sur `history.undo()` / `history.redo()`.
  - `apps/web/src/canvas/board-canvas.tsx` : utilise `useHistoryShortcuts`.
- Code technique : aucun : `Y.UndoManager` (`createBoardHistory`), le contexte d'historique et `BoardHistory` existent depuis F07-S2.
- Code de test :
  - Unitaire : `packages/model/src/history.test.ts` (`[F08-S2-AC1]` : annuler un déplacement puis une création, rétablir ; `[F08-S2-AC2]` : une transaction d'origine distante n'est pas annulée).
  - Unitaire : `apps/web/src/tools/history-shortcuts.test.tsx` (`[F08-S2-AC1]` : `Ctrl+Z` annule, `Ctrl+Shift+Z` rétablit, inactif dans un champ).
  - Unitaire : `apps/web/src/components/board/toolbar.test.tsx` (`[F08-S2-AC3]` : boutons désactivés sans historique puis actifs après une action, clic `undo`/`redo` ; `[UI-BOARD-3]` : séparateur entre les outils et les boutons d'historique).
  - E2E : `e2e/undo-redo.spec.ts` (`[F08-S2-AC1]` : création puis déplacement annulés et création rétablie ; `[F08-S2-AC3]` : boutons désactivés/actifs et clic) ; `e2e/undo-redo-collab.spec.ts` (`[F08-S2-AC2]` : à deux utilisateurs, l'annulation de A laisse B chez les deux).
- Documentation et Markdown : `docs/architecture.md` (flux d'annulation/rétablissement et barre d'outils), `docs/journal.md` (décisions : nom du hook, rétablissement `Ctrl+Shift+Z`, composant `separator`), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F08-S2.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F08-S2-AC1 à AC3) ; après création puis déplacement d'un post-it, deux `Ctrl+Z` annulent le déplacement puis la création et `Ctrl+Shift+Z` rétablit la création ; annuler chez un utilisateur ne supprime pas l'élément créé par l'autre, chez les deux ; les boutons `undo`/`redo` sont désactivés quand il n'y a rien à annuler ou rétablir.
