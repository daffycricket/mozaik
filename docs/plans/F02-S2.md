## Étapes

### Étape 1 : zoomer au pointeur, aux boutons et au clavier

- Critères d'acceptance couverts : F02-S2-AC1, F02-S2-AC2, F02-S2-AC3, F02-S2-AC4, UI-BOARD-5, UI-BOARD-6
- Code applicatif :
  - `packages/model/src/viewport.ts` : `MIN_ZOOM`, `MAX_ZOOM`, `ZOOM_STEP`, `clampZoom(zoom)` et `zoomViewport(viewport, zoom, screenPoint)` (garde le point monde sous `screenPoint` fixe).
  - `apps/web/src/state/viewport-store.ts` : actions `zoomTo(zoom, screenPoint)` et `zoomBy(factor, screenPoint)`.
  - `apps/web/src/state/canvas-size-store.ts` : taille du canvas (état local) pour ancrer le zoom des boutons et du clavier au centre du canvas.
  - `apps/web/src/canvas/use-zoom.ts` : `useWheelZoom` (`Ctrl`/`Cmd` + molette, centré sur le pointeur).
  - `apps/web/src/canvas/use-pan.ts` : la molette avec `Ctrl`/`Cmd` est laissée au zoom.
  - `apps/web/src/canvas/board-canvas.tsx` : publie la taille du canvas et branche le zoom à la molette ; la grille suit le zoom.
  - `apps/web/src/tools/shortcuts.ts` : `useZoomShortcuts` (`Ctrl+=`, `Ctrl+-`, `Ctrl+0`).
  - `apps/web/src/components/board/zoom-controls.tsx` : `ZoomControls` (`zoom-controls`, boutons `zoom-out` et `zoom-in`, pourcentage `zoom-level`), flottant en bas à droite.
  - `apps/web/src/app/board-page.tsx` : branche `useZoomShortcuts` et rend `ZoomControls` dans `BoardShell`.
- Code technique : aucun : les dépendances (zustand, lucide-react) existent déjà.
- Code de test :
  - Unitaire : `packages/model/src/viewport-zoom.test.ts`, `apps/web/src/state/viewport-store-zoom.test.ts`, `apps/web/src/state/canvas-size-store.test.ts`, `apps/web/src/tools/zoom-shortcuts.test.tsx`, `apps/web/src/components/board/zoom-controls.test.tsx`.
  - E2E : `e2e/board-zoom.spec.ts` (F02-S2-AC1, AC2, AC3), `e2e/fluidity/board-zoom.spec.ts` (F02-S2-AC4, mesures FL-2 et FL-3), `e2e/layout/board-zoom.spec.ts` (UI-BOARD-5, UI-BOARD-6 aux deux viewports).
- Documentation et Markdown : `docs/architecture.md` (zoom dans `canvas/`, `state/`), `docs/journal.md` (décisions), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F02-S2.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F02-S2-AC1 à AC4 et UI-BOARD-5, UI-BOARD-6), le zoom centré sur le pointeur conserve le point monde sous le curseur, les bornes 10 %–400 % sont tenues, les contrôles et raccourcis mettent le pourcentage à jour, et le zoom à la molette d'un board de 300 éléments respecte FL-2 et FL-3.
