## Étapes

### Étape 1 : design system et harnais de conformité aux maquettes

- Critères d'acceptance couverts : T-006-AC1, T-006-AC2, T-006-AC3, T-006-AC4, T-006-AC5, T-006-AC6, T-006-AC7
- Code applicatif :
  - `apps/web/src/index.css` : import Tailwind v4 et `tw-animate-css`, variables du thème shadcn/ui `neutral` **sans modification**, puis les jetons du projet de `design/charte.md` (T-006-AC2).
  - `apps/web/src/lib/utils.ts` : `cn` (shadcn/ui).
  - `apps/web/src/lib/theme-tokens.ts` : les jetons du projet exposés au rendu Konva (`PROJECT_TOKENS`, `readProjectToken`) (T-006-AC2).
  - `apps/web/src/components/ui/button.tsx` : seul composant shadcn/ui ajouté (T-006-AC1).
  - `apps/web/src/main.tsx` : import de `./index.css`.
  - `apps/web/src/testing/board-api.ts` : `getOverlayBoxes()` et le calcul pur des boîtes à l'écran (cadre de sélection, 8 poignées, curseurs distants) (T-006-AC6).
- Code technique :
  - `apps/web/components.json` : configuration shadcn/ui (Base UI, `neutral`, alias `@` vers `src`) (T-006-AC1).
  - `apps/web/vite.config.ts` : plugin `@tailwindcss/vite` (T-006-AC1).
  - `apps/web/package.json` : dépendances du design system (T-006-AC1).
  - `tooling/check-colors.ts` et `tooling/check-colors-cli.ts` : détecteur de couleurs en dur ; branché dans `pnpm lint` (`package.json`) (T-006-AC7).
  - `e2e/support/layout.ts` : utilitaires de mise en page de `process/testing.md` (T-006-AC3).
  - `playwright.config.ts` : projet `layout` (viewports 1280 × 800 et 1024 × 768), exclusion du projet `chromium` (T-006-AC4).
- Code de test :
  - Unitaire : `apps/web/src/lib/theme-tokens.test.ts` (chaque jeton de la charte déclaré dans `index.css` avec sa valeur) ; `apps/web/src/lib/utils.test.ts` ; `apps/web/src/components/ui/button.test.tsx` ; `apps/web/src/testing/board-api.test.ts` (`computeOverlayBoxes`, ajout) ; `tooling/design-system.test.ts` (T-006-AC1) ; `tooling/check-colors.test.ts` (T-006-AC7) ; `tooling/ac-check.test.ts` (ajout d'un cas `[T-006-AC5]`).
  - E2E : `e2e/layout/layout-utils.spec.ts` (cas qui passent et cas qui échouent sur une page de démonstration, T-006-AC3) ; `e2e/layout/viewports.spec.ts` (les deux viewports de référence, T-006-AC4) ; `e2e/board-overlay.spec.ts` (`getOverlayBoxes` sur un board vide, T-006-AC6).
- Documentation et Markdown : `docs/architecture.md` (design system et `getOverlayBoxes` désormais réels), `docs/journal.md` (décisions et dépendances), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/T-006.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (les trois projets Playwright passent), `pnpm lint` refuse une couleur en dur introduite volontairement, et les jetons de la charte sont déclarés dans `index.css`.
