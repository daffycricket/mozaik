## Étapes

### Étape 1 : barre contextuelle de couleur

- Critères d'acceptance couverts : F03-S3-AC1, F03-S3-AC2, F03-S3-AC3, UI-BOARD-7
- Code applicatif :
  - `packages/model/src/ops.ts` : `setElementsColor(doc, ids, color)` écrit la couleur des post-its et textes indiqués dans une seule transaction à origine locale (une action = une entrée d'annulation, `process/code.md` §5) ; les autres types sont ignorés.
  - `apps/web/src/components/board/context-bar.tsx` : barre contextuelle flottante (rôle `toolbar`) affichée seulement si la sélection contient au moins un post-it ou un texte ; 10 pastilles `color-<code>` issues de `PALETTE_COLORS` (couleur de fond de `PALETTE`), `aria-pressed="true"` sur la couleur courante (aucune si les couleurs diffèrent), au clic appelle `setElementsColor` ; positionnée centrée horizontalement au-dessus du cadre de sélection à 8 px, ou en dessous si la place manque, sans recouvrir la sélection (UI-BOARD-7).
  - `apps/web/src/app/board-page.tsx` : `BoardShell` rend `<ContextBar />` dans la zone du canvas.
- Code technique : aucun : les dépendances (zustand, react-konva, toggle-group) existent déjà.
- Code de test :
  - Unitaire : cas `setElementsColor` dans `packages/model/src/ops.test.ts` (F03-S3-AC1), `apps/web/src/components/board/context-bar.test.tsx` (F03-S3-AC1, F03-S3-AC2).
  - E2E : `e2e/sticky-color.spec.ts` (F03-S3-AC1, F03-S3-AC2), `e2e/layout/board-context-bar.spec.ts` (UI-BOARD-7, aux deux viewports de référence), `e2e/fluidity/sticky-color.spec.ts` (F03-S3-AC3 : FL-1).
- Documentation et Markdown : `docs/architecture.md` (barre contextuelle, `setElementsColor`, flux de changement de couleur), `docs/journal.md` (décisions et tests), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F03-S3.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F03-S3-AC1 à AC3 et UI-BOARD-7) ; sélectionner un ou plusieurs post-its affiche la barre contextuelle avec les 10 couleurs, la couleur courante est marquée `aria-pressed="true"`, choisir `blue` recolore tous les post-its sélectionnés, la barre est centrée au-dessus de la sélection à 8 px (ou en dessous sans la recouvrir), et le changement est visible localement en ≤ 150 ms même avec 300 ms de latence réseau simulée.
