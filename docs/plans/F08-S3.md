## Étapes

### Étape 1 : Opérations de copie dans le modèle

- Critères d'acceptance couverts : F08-S3-AC1, F08-S3-AC2, F08-S3-AC3 (au niveau des données et des opérations pures)
- Code applicatif :
  - `packages/model/src/ops.ts` : `serializeElements`, `parseElements`, `pasteElements`, `duplicateElements`, préfixe `CLIPBOARD_PREFIX`, option `generateId` injectée, décalage `COPY_OFFSET` (+20, +20), zIndex calculés au-dessus des originaux via `generateKeyBetween`, écriture en une transaction `LOCAL_ORIGIN`.
- Code technique : aucun.
- Code de test : `packages/model/src/clipboard.test.ts` (unitaire) : cas `[F08-S3-AC1]` (duplication : nouveaux ids, décalage, au-dessus, ordre relatif conservé), `[F08-S3-AC2]` (sérialiser → analyser → coller = duplication), `[F08-S3-AC3]` (coller dans un document vide donne de nouveaux ids), plus les cas de rejet du format préfixé.
- Documentation et Markdown : `docs/architecture.md` (flux « Dupliquer, copier, coller »), `docs/glossary.md` (entrées `duplicate`, `clipboard`), section de l'étape dans `docs/test-reports/F08-S3.md`.
- Terminée quand : `pnpm verify` vert, les trois cas nommés présents, et `pnpm ac:check` ne signale plus F08-S3-AC1/AC2/AC3 comme non couverts.

### Étape 2 : Raccourcis et presse-papiers côté web

- Critères d'acceptance couverts : F08-S3-AC1, F08-S3-AC2, F08-S3-AC3
- Code applicatif :
  - `apps/web/src/lib/clipboard.ts` : `writeClipboard`/`readClipboard` (presse-papiers système via `navigator.clipboard`, repli mémoire si l'accès est refusé) ;
  - `apps/web/src/tools/shortcuts.ts` : `useClipboardShortcuts(doc)` (`Ctrl+D` duplique, `Ctrl+C` copie, `Ctrl+V` colle et sélectionne les copies ; inactif pendant l'édition d'un texte ou dans un champ) ;
  - `apps/web/src/canvas/board-canvas.tsx` : branche le hook.
- Code technique : aucun.
- Code de test :
  - unitaire `apps/web/src/lib/clipboard.test.ts` (repli mémoire quand l'accès est refusé) ;
  - unitaire `apps/web/src/tools/clipboard-shortcuts.test.tsx` (cas `[F08-S3-AC1]`, `[F08-S3-AC2]`, `[F08-S3-AC3]` au niveau du hook) ;
  - e2e `e2e/duplicate.spec.ts` (cas `[F08-S3-AC1]`, `[F08-S3-AC2]`, `[F08-S3-AC3]` : duplication d'un post-it, d'un texte et d'une flèche, copier/coller dans le board, copier/coller entre deux boards).
- Documentation et Markdown : `docs/architecture.md` (raccourcis et presse-papiers), `docs/glossary.md` si nécessaire, `docs/backlog.md` (F08-S3 → `done`), section de l'étape dans `docs/test-reports/F08-S3.md`, `docs/journal.md` (décision de format de presse-papiers).
- Terminée quand : `pnpm verify` vert, `e2e/duplicate.spec.ts` au vert, `pnpm ac:check` vert, ticket `done` dans le backlog.
