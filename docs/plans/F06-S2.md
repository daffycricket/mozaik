## Étapes

### Étape 1 : modifier une flèche

- Critères d'acceptance couverts : F06-S2-AC1, F06-S2-AC2, F06-S2-AC3
- Code applicatif :
  - `packages/model/src/geometry.ts` : `ArrowEndpoint` (`'start' | 'end'`), `distanceToSegment(point, a, b)`, `arrowEndpointAtPoint(arrow, point, tolerance)` et `arrowWithEndpointMoved(arrow, endpoint, point)` (AC1).
  - `packages/model/src/ops.ts` : `elementAtPoint` accepte une tolérance optionnelle ; une flèche est touchée à proximité de son segment (et non dans toute sa boîte englobante), pour que le glisser du corps de F06-S2-AC2 ne capture pas les clics dans le vide de sa boîte.
  - `apps/web/src/canvas/use-select.ts` : démarre un glisser d'extrémité quand une flèche seule est sélectionnée et que le pointeur est sur une de ses deux poignées ; écrit la nouvelle extrémité via `updateElement` au plus toutes les 50 ms, encadré par `stopCapturing()` (une entrée d'annulation) ; passe la tolérance des poignées à `elementAtPoint` pour le glisser du corps (déjà géré par `moveElements`).
- Code technique : aucun : les dépendances existent déjà.
- Code de test :
  - Unitaire : `packages/model/src/arrow.test.ts` (`distanceToSegment`, `arrowEndpointAtPoint`, `arrowWithEndpointMoved` AC1 ; `elementAtPoint` avec tolérance sur le segment AC2 ; `moveElements` déplace les deux extrémités AC2).
  - E2E : `e2e/arrow-edit.spec.ts` (F06-S2-AC1 : glisser la poignée d'arrivée ; F06-S2-AC2 : glisser le corps), `e2e/fluidity/arrow-edit.spec.ts` (F06-S2-AC3, FL-1 et FL-2 sur un board de 300 éléments).
- Documentation et Markdown : `docs/features/F06-fleches.md` (ajout de F06-S2-AC3, fluidité), `docs/architecture.md` (modification d'une flèche : extrémités et corps), `docs/journal.md` (décisions et spec), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F06-S2.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F06-S2-AC1 à AC3) ; glisser la poignée d'arrivée d'une flèche sélectionnée déplace l'arrivée sans bouger le départ ; glisser le corps déplace les deux extrémités du même vecteur ; et le glisser d'une extrémité sur un board de 300 éléments respecte FL-1 (≤ 150 ms) et FL-2 (médiane ≤ 33 ms, aucun intervalle > 200 ms).
