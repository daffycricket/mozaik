## Étapes

### Étape 1 : socle collaboratif

- Critères d'acceptance couverts : T-003-AC1, T-003-AC2, T-003-AC3, T-003-AC4, T-003-AC5
- Code applicatif :
  - Modèle : `packages/model/src/schema.ts` (types et schémas zod des éléments, palette), `packages/model/src/doc.ts` (`createBoardDoc`), `packages/model/src/ops.ts` (`LOCAL_ORIGIN`, `getElements`, `createElement`, `updateElement`, `deleteElements`), `packages/model/src/viewport.ts` (conversions monde/écran), `packages/model/src/index.ts` (exports).
  - Serveur : `apps/server/src/db/migrations.ts` (table `documents`), `apps/server/src/db/documents.ts` (lecture/écriture/suppression de l'état Yjs), `apps/server/src/db/boards.ts` (`boardExists`, `deleteBoard`), `apps/server/src/collab/server.ts` (Hocuspocus sur `/collab`, extension base de données, garde d'existence, `closeBoard`), `apps/server/src/app.ts` (montage, seed pré-rempli, arrêt propre), `apps/server/src/http/boards.ts` (`DELETE /api/boards/:id`).
  - Web : `apps/web/src/collab/use-board-connection.ts` (provider Hocuspocus), `apps/web/src/testing/board-api.ts` (`window.__board` en mode `VITE_E2E`), `apps/web/src/canvas/board-canvas.tsx` (stage Konva), `apps/web/src/app/board-page.tsx` (connexion et exposition), `apps/web/src/app/app.tsx` (passage de `boardId`).
- Code technique : dépendances `yjs`, `zod`, `fractional-indexing` (modèle) ; `@hocuspocus/server`, `@hocuspocus/extension-database`, `crossws` (serveur) ; `@hocuspocus/provider`, `konva`, `react-konva` (web) ; `@hocuspocus/provider` (dev, serveur).
- Code de test :
  - Unitaire : `packages/model/src/schema.test.ts`, `doc.test.ts`, `ops.test.ts`, `viewport.test.ts` ; `apps/server/src/db/documents.test.ts` ; `apps/web/src/testing/board-api.test.ts`.
  - Intégration : `apps/server/test/collab.int.test.ts` (chargement/enregistrement SQLite, refus d'un board inconnu, fermeture à la suppression).
  - E2E : `e2e/board-collab.spec.ts` (connexion WebSocket, `window.__board` sur un board vide).
- Documentation et Markdown : `docs/architecture.md` (état réel du socle), `docs/journal.md` (décisions et dépendances), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/T-003.md` (étape 1).
- Terminée quand : les tests unitaires, d'intégration et e2e passent, la couverture de `packages/model` est ≥ 90 %, et `pnpm verify` est vert.
