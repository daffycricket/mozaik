## Étapes

### Étape 1 : redimensionner par les poignées, proportions, taille minimale et fluidité

- Critères d'acceptance couverts : F07-S3-AC1, F07-S3-AC2, F07-S3-AC3, F07-S3-AC4
- Code applicatif :
  - `packages/model/src/resize.ts` : `MIN_ELEMENT_SIZE` (taille minimale d'un élément redimensionnable), `RESIZE_HANDLE_ORDER`/`ResizeHandle`, `resizeHandlePoint(box, handle)`, `resizeHandleAtPoint(box, point, tolerance)`, `isResizable(element)` et `resizeBox(box, handle, pointer, options)` (nouvelle boîte pure : coin opposé fixe, proportions avec Shift, bornage à `MIN_ELEMENT_SIZE`).
  - `packages/model/src/index.ts` : exporte le module `resize`.
  - `apps/web/src/canvas/selection-handles.ts` : `selectionHandles` s'appuie sur `RESIZE_HANDLE_ORDER`/`resizeHandlePoint` (source unique des 8 poignées, UI-BOARD-10).
  - `apps/web/src/canvas/use-select.ts` : un appui sur une poignée de la sélection, quand un seul élément redimensionnable est sélectionné, démarre un redimensionnement (`resizeBox` + `updateElement`), écrit au plus toutes les 50 ms et encadre le geste par `stopCapturing()` pour une seule annulation (F07).
- Code technique : aucun : les dépendances (yjs, react-konva, zustand) existent déjà.
- Code de test :
  - Unitaire : `packages/model/src/resize.test.ts` (`resizeBox` coin/côté, Shift, minimum ; `resizeHandleAtPoint` ; `isResizable`).
  - E2E : `e2e/resize.spec.ts` (`[F07-S3-AC1]`, `[F07-S3-AC2]`, `[F07-S3-AC3]`).
  - Fluidité : `e2e/fluidity/board-resize.spec.ts` (`[F07-S3-AC4]` : FL-1 et FL-2 sur 300 éléments).
- Documentation et Markdown : `docs/architecture.md` (flux de redimensionnement, opérations et helpers), `docs/glossary.md` (taille minimale), `docs/journal.md` (décisions et tests), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F07-S3.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F07-S3-AC1 à AC4) ; glisser la poignée bas-droite d'un élément change sa largeur et sa hauteur en gardant le coin haut-gauche fixe, Shift conserve le rapport largeur/hauteur, une réduction exagérée est bornée à `MIN_ELEMENT_SIZE`, et les mesures FL-1/FL-2 de redimensionnement sur 300 éléments sont sous les seuils de F00.
