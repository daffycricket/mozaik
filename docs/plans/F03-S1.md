## Étapes

### Étape 1 : créer un post-it au clic et au double-clic

- Critères d'acceptance couverts : F03-S1-AC1, F03-S1-AC2, F03-S1-AC3, F03-S1-AC4
- Code applicatif :
  - `packages/model/src/schema.ts` : `STICKY_DEFAULT_SIZE` (200), `STICKY_FONT_SIZE` (20), `stickyTextColor(color)` (couleur de texte d'un post-it, blanc sur `black`).
  - `packages/model/src/ops.ts` : `createSticky(doc, center, options)` crée un post-it 200 × 200 jaune centré sur `center`.
  - `packages/model/src/geometry.ts` : `Box` et `unionBounds(boxes)` (boîte englobante de la sélection).
  - `apps/web/src/state/selection-store.ts` : sélection locale (`selection`, `setSelection`, `clearSelection`).
  - `apps/web/src/state/editing-store.ts` : édition locale (`editingId`, `startEditing`, `stopEditing`).
  - `apps/web/src/state/tool-store.ts` : outil `sticky`.
  - `apps/web/src/tools/shortcuts.ts` : raccourci `N` vers l'outil Post-it.
  - `apps/web/src/components/board/toolbar.tsx` : bouton `tool-sticky` (icône `sticky-note`, libellé « Post-it (N) »).
  - `apps/web/src/collab/board-doc-context.ts` : contexte React du document du board.
  - `apps/web/src/canvas/use-elements.ts` : abonnement aux éléments du document.
  - `apps/web/src/canvas/board-elements.tsx` : rendu Konva des post-its (fond de la palette, texte centré).
  - `apps/web/src/canvas/selection-overlay.tsx` : cadre de sélection (1 px `--selection`).
  - `apps/web/src/canvas/use-create.ts` : création par clic (outil Post-it) et par double-clic (outil Sélection + édition).
  - `apps/web/src/canvas/board-canvas.tsx` : rendu des éléments, de la sélection et de l'éditeur ; branche les créations.
  - `apps/web/src/components/board/text-editor.tsx` : zone de saisie `text-editor` superposée au post-it, valide sur Échap ou perte de focus.
  - `apps/web/src/app/board-page.tsx` : fournit le document via le contexte et branche la sélection dans `window.__board`.
  - `apps/web/src/testing/board-api.ts` : `getSelection` injectable et boîte de sélection dans `getOverlayBoxes()`.
- Code technique : aucun : les dépendances (zustand, react-konva, lucide-react) existent déjà.
- Code de test :
  - Unitaire : `packages/model/src/sticky.test.ts` (AC1, AC3, couleur de texte), `packages/model/src/geometry.test.ts`, `apps/web/src/state/selection-store.test.ts`, `apps/web/src/state/editing-store.test.ts`, `apps/web/src/tools/sticky-shortcut.test.tsx`, `apps/web/src/components/board/text-editor.test.tsx`, `apps/web/src/testing/board-api-selection.test.ts`.
  - E2E : `e2e/sticky-create.spec.ts` (F03-S1-AC1, AC2, AC3), `e2e/fluidity/sticky-create.spec.ts` (F03-S1-AC4, mesure FL-1 avec 300 ms de latence réseau simulée).
- Documentation et Markdown : `docs/architecture.md` (rendu des éléments, sélection, édition, nouveaux stores), `docs/journal.md` (décisions et tests), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F03-S1.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur F03-S1-AC1 à AC4), un clic avec l'outil Post-it crée un post-it 200 × 200 jaune centré, sélectionné, et remet l'outil Sélection, un double-clic sur une zone vide crée un post-it et ouvre l'éditeur, le nouveau post-it a un `zIndex` supérieur, et la création d'un post-it sur un board de 300 éléments respecte FL-1 (≤ 150 ms, y compris avec 300 ms de latence).
