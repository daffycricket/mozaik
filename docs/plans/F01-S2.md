## Étapes

### Étape 1 : menu des boards, navigation et URL partagée

- Critères d'acceptance couverts : F01-S2-AC1, F01-S2-AC2, F01-S2-AC3, F01-S2-AC4, F01-S2-AC5, F01-S2-AC6, UI-MENU-1, UI-MENU-2, UI-MENU-3, UI-MENU-4, UI-MENU-5, UI-BOARD-1
- Code applicatif :
  - `apps/server/src/db/boards.ts` : `listBoards` (tri par `updated_at` décroissant) et `getBoard`.
  - `apps/server/src/http/boards.ts` : `GET /api/boards` et `GET /api/boards/:id` (404 sinon).
  - `apps/web/src/lib/boards-api.ts` : `listBoards` et `getBoard`.
  - `apps/web/src/lib/relative-date.ts` : `formatRelativeDate` (il y a N min/h, hier, le JJ/MM).
  - `apps/web/src/app/board-list-page.tsx` : en-tête « Boards » + bouton `board-create`, liste `board-list` centrée (≤ 720 px), lignes `board-item` (nom, date relative, bouton `board-delete`), état vide `board-empty` + `board-empty-create`, ouverture d'un board.
  - `apps/web/src/app/board-page.tsx` : en-tête `board-header` (`nav-boards` + `board-name`) au-dessus du canvas.
  - `apps/web/src/canvas/board-canvas.tsx` : le stage prend la taille de son conteneur (le canvas occupe l'espace sous l'en-tête).
- Code technique :
  - `e2e/support/identity.ts` : (aucun changement prévu, l'identité mémorisée par défaut reste utilisée).
- Code de test :
  - Unitaire : `apps/web/src/lib/relative-date.test.ts`, `apps/web/src/lib/boards-api.test.ts` (list/get), `apps/web/src/app/pages.test.tsx` (rendu menu liste/vide, en-tête board).
  - Intégration : `apps/server/test/boards.int.test.ts` (liste triée, lecture par id, 404) et `apps/server/src/db/boards.test.ts`.
  - E2E : `e2e/board-list.spec.ts` (F01-S2-AC1 à AC5), `e2e/layout/board-list.spec.ts` (UI-MENU-1 à UI-MENU-5, UI-BOARD-1), `e2e/fluidity/menu-board.spec.ts` (F01-S2-AC6).
- Documentation et Markdown : `docs/journal.md` (décisions, dont le `data-testid` de l'état vide, le bouton Supprimer différé à F01-S4 et les tests hérités adaptés), `docs/design/composants.md` (testid du bouton de l'état vide), `docs/backlog.md` (statut `done`), rapport `docs/test-reports/F01-S2.md` (étape 1).
- Terminée quand : `pnpm verify` est vert (y compris `ac:check` sur les critères F01-S2 et les règles `UI-MENU-*` / `UI-BOARD-1`), l'ouverture d'un board depuis le menu et le retour au menu passent, et une URL `/b/<id>` ouverte sans nom mémorisé demande le nom puis affiche le board.
